# 极简白底学术 PPT 设计规范

## 1. 画布与空间网格

- **尺寸**：16:9 标准宽屏 `13.333 in × 7.5 in`（`33.87 cm × 19.05 cm`）
- **背景**：纯白 `#FFFFFF`，不加四周装饰大边框、不加背景水印。
- **边距**：左右各 `0.60 in`，内容可用宽度 `12.133 in`（`x = 0.60 .. 12.733`）。
- **页眉区**（`y = 0.25 .. 1.04`）：
  - 左上纯文字章节标签（`10pt Bold`，主色或强调色，不加左侧粗彩竖条）
  - 顶部一句话结论标题（`19–20pt Bold`，`#0F172A`，严格单行，不超过约 34 个汉字）
  - `y = 1.04` 处一根 `0.75pt` 极细灰线 `#E2E8F0`
- **主内容安全区**：`y = 1.18 .. 6.98`（高 `5.80 in`）
- **页脚区**（`y = 7.08 .. 7.40`）：`0.5pt` 细灰线 + 左下汇报短标题（`8.5pt #94A3B8`）+ 右下页码 `k / N`（`9pt Bold #64748B`）

---

## 1.5 视觉去 AI 味红线（严禁“竖线 + 淡色背景框”堆砌）

“左侧彩色竖条 + 浅色矩形底框”（Notion/Tailwind Callout 风格）是最容易一眼暴露 AI 生成感的版式套路。极简学术白底 PPT 必须遵循**去盒化（No Box-itis）**原则：

1. **文字直接落在纯白画布上**：常规背景说明、方法拆解、实验解读、两栏/三栏对比与讨论议题，一律**不加背景底色、不加边框、不加左侧粗彩竖条**。
2. **用排版几何而非色块建立层次**：
   - 区块之间依靠 **充足留白（0.25–0.40 in）**、**极细水平线（`0.5–0.75pt #E2E8F0` 或局部 `1.25pt` 短顶线）**、**轻细垂直分隔线（`0.5pt #E2E8F0`）** 以及 **小标题字重/颜色梯度** 自然区分；
   - 重要数字与关键词直接通过字号放大或主色/强调色加粗突出，无需再套彩色卡片底盒。
3. **浅色底盒严格限流**：
   - 严禁使用“粗彩竖线（accent bar）+ 淡色底”组合；
   - 无竖条的极轻浅灰/浅色底盒（如 `#F8FAFC`，细灰边框或无边框）仅允许用于**数学公式块、或全套 PPT 最核心的 1–2 处单行结论/局限批注**，**单页最多 1 个，全套（8–12 页）总数不超过 3 个**；
   - 禁止同一页出现红、橙、蓝、绿多块彩色底框拼贴。

## 2. 克制配色系统

严禁五颜六色或深色大块背景压迫画面；全局最多使用 **1 主色 + 1 辅色 + 1 强调色** + 灰阶：

| 角色 | Hex | 用途 |
|---|---|---|
| 画布底色 | `#FFFFFF` | 页面背景（绝大多数正文直接落于纯白底） |
| 极轻浅灰 | `#F8FAFC` | 表格偶行斑马纹；极克制地用于公式块或全套 ≤3 处无竖条结论条 |
| 细分割线 | `#E2E8F0` | 页眉/页脚线、图片细边框、表格横线、纯白分栏细分隔线 |
| 主文字（深墨蓝） | `#0F172A` | 标题、表头背景、加粗关键词 |
| 正文文字 | `#334155` | 正文要点、表格主体 |
| 弱化文字 | `#64748B` / `#94A3B8` | 图注出处、页脚、空值 `—` |
| 主色（学术钴蓝） | `#1D4ED8` / `#1E3A8A` | 章节标签、小标题、关键词高亮、局部极细顶线（禁止大面积铺浅蓝底盒） |
| 辅色（深青绿） | `#0F766E` | 硬件/系统小标题、已覆盖符号 `●` |
| 强调色（暖橙/红） | `#D9480F` / `#DC2626`（仅表格高亮行可用 `#FFF7ED`） | 研究空白、关键局限文字高亮、三线表本课题高亮行（克制使用） |

## 3. 字体与字号梯度

- **字体**：统一使用 `Microsoft YaHei`（微软雅黑，Windows PowerPoint/WPS 原生美观，中英文基线对齐；Linux 预览时可回退至 `WenQuanYi Zen Hei`）。
- **字号底线**（保证投影室后排清晰可读）：
  - 封面主标题：`34–36pt Bold`
  - 封面副标题：`14–15pt`
  - 内容页结论标题：`19–20pt Bold`
  - 卡片/区块小标题：`12.5–14pt Bold`
  - 正文要点：`11.5–13pt`（绝不降到 `10pt` 以下挤密字）
  - 表格文字：`10–10.5pt`（表头 `10.5–11pt Bold`）
  - 论文图注出处：`9–9.5pt` `#64748B`

---

## 4. 常用版式搭配（避免连续两页雷同）

1. **封面**：左文右图（右侧放纯白底极简等轴测插画，无缝融入白底）。
2. **问题出发点**：左图（生图概念图或论文实测图）+ 右侧（精简三线表 + 纯白底编号要点，用一根细灰横线隔开）。
3. **架构/机制拆解**：左侧大图 + 右侧纯白底分层要点（段落间用 `0.5pt` 细灰横线或充足留白分隔，不套浅色卡片盒）。
4. **全景矩阵 / 竞品对比**：整页原生学术三线表（去竖线，仅保留横线；表头深墨蓝 `#0F172A`；竞品能力用 `●` 青绿 / `◐` 琥珀 / `○` 浅灰居中打点；本课题行可用 `#FFF7ED` 轻高亮）。
5. **双向/双机制深挖**：上方左右并排 2 张 300 DPI 论文原图（带极细灰框 `#E2E8F0` 和出处）+ 下方 2–3 列纯白底解读（列顶用极细 `1.0–1.25pt` 短横线或列间 `0.5pt` 细灰竖线分隔，零底色盒）。
6. **竞品单篇拆解**：上方大图 + 原生红色虚线框直接圈出图中盲区 + 下方左右纯白底对照（中间一根 `0.5pt` 细灰竖线分隔）。
7. **总结与讨论**：左右两栏纯白底大留白排版（中间一根 `0.5pt` 细灰竖线），左侧方法提炼，右侧开放讨论议题。

## 5. 调用生图模型（`image-generator`）的铁律模板

生图模型只适合画**封面主视觉**和**抽象概念/竞争关系图**（不适合画带大量精确中英文文字的架构图或数据曲线）。提示词必须显式包含以下约束：

```text
Style: Clean minimalist flat/isometric scientific editorial illustration (Apple engineering keynote / Nature diagram aesthetic).
Background: PURE SOLID WHITE (#FFFFFF) background with generous clean margins so it blends seamlessly onto a white slide.
CRITICAL TEXT RULE: ABSOLUTELY NO TEXT, NO LETTERS, NO NUMBERS, NO LABELS anywhere inside the image.
Color palette: Deep Navy Blue (#1E3A8A), Slate Gray (#64748B), Deep Teal (#0F766E), and ONE subtle Warm Vermilion accent (#EA580C).
Avoid: 3D neon cyberpunk, heavy gradients, dark backgrounds, busy clutter, corporate clipart.
```

生成后用 `python-pptx` 在对应位置叠加原生中文标签，既美观又完全可编辑、零乱码。
